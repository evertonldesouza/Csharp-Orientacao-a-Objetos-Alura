# Formação C# e Orientação a Objetos - Alura

![.NET](https://img.shields.io/badge/.NET-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)
![Visual Studio](https://img.shields.io/badge/Visual_Studio-5C2D91?style=for-the-badge&logo=visual%20studio&logoColor=white)

Repositório dedicado aos projetos e exercícios desenvolvidos durante a formação de C# e Orientação a Objetos da plataforma Alura. O projeto principal construído ao longo dos módulos é o sistema bancário **ByteBank**.

## Índice de Módulos e Aprendizados

Abaixo está a trilha de conhecimento percorrida, dividida por módulos:

| Módulo | Tópicos Abordados |
| :--- | :--- |
| **1. Primeiros Passos** | Tipos de variáveis, conversões (casting), ponto flutuante, escopo e laços de repetição (`for`, `while`). |
| **2. Orientação a Objetos** | Classes, objetos, métodos, propriedades, encapsulamento e namespaces. Criação do ByteBank. |
| **3. Herança e Interface** | Polimorfismo, classes abstratas, interfaces (`IAutenticavel`), modificadores `virtual` e `override`. |
| **4. Entendendo Exceções** | Pilha de chamadas (Call Stack), blocos `try/catch/finally`, `throw` e criação de exceções customizadas (`SaldoInsuficienteException`). |
| **5. Bibliotecas, DLLs e NuGet** | Criação e importação de bibliotecas (DLLs), documentação XML, pacote Humanizer e gerenciamento pelo NuGet. |
| **6. Strings e RegEx** | Manipulação de strings, métodos da classe `Object` (`Equals`, `ToString`), e Expressões Regulares (RegEx). |
| **7. Arrays e Genéricos** | Arrays no C#, criação de classes genéricas (`<T>`), indexadores e manipulação de listas customizadas. |
| **8. List, Lambda e LINQ** | Uso da interface `IList`, expressões Lambda, métodos de extensão e consultas com LINQ (`Where`, `OrderBy`). |
| **9. Entrada e Saída (Streams)** | Manipulação de arquivos, `FileStream`, `StreamReader`, `StreamWriter` e leitura/escrita de dados binários. |

## Como Executar

1. Certifique-se de ter o **Visual Studio** (ou VS Code) e o **.NET Framework** instalados.
2. Clone este repositório:
   ```bash
   git clone [https://github.com/evertonldesouza/csharp-orientacao-a-objetos-alura.git](https://github.com/evertonldesouza/csharp-orientacao-a-objetos-alura.git)
   ```
